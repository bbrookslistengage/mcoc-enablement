## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Required fields mapping between form fields and Salesforce objects
- Adding a consent banner to a landing page
- Building a VisionCare Rewards signup page with First Name, Last Name, Email, Phone, and "How did you hear about us" fields
- Testing form submission end-to-end and verifying Lead creation
