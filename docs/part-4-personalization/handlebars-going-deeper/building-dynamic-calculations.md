## Overview

## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Building eye exam reminder messaging using `DateDiff` to calculate months since last visit
- Calculating points needed to reach the next loyalty tier with math helpers
- Using `QueryFirst` to look up product details from a Marketing Object by product ID
- Formatting currency values with `FormatCurrency` for price displays
- Combining multiple advanced helpers in a single content block
- Using `RaiseError` to debug expressions that return unexpected results
