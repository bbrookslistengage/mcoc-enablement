## Overview

## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Math helpers for arithmetic operations in email content
- Date helpers and `DateDiff` for calculating time intervals
- `Format`, `FormatCurrency`, and `FormatNumber` for display formatting
- `Query` and `QueryFirst` for looking up records in Marketing Objects
- `GetContentBlock` for pulling reusable content blocks into emails
- `Set` and `Hash` for defining and organizing local variables
- JSONPath expressions for navigating complex data structures
- `RaiseError` as a debugging tool during development
- Filtering and sorting related lists within Handlebars expressions
- How to approach this module as reference material rather than required memorization
