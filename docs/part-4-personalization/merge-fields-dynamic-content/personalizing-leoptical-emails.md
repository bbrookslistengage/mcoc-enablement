## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Adding merge fields for first name, loyalty tier, and points balance to an LEOptical email
- Connecting data graph attributes through the Data Sources tab
- Setting up content variables for values used in multiple content blocks
- Creating dynamic content variations that display different messaging per loyalty tier
- Previewing personalized content with test contact records
- Identifying cases where no-code personalization falls short for LEOptical's needs
