## Overview

## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- The Data Sources tab in the email content editor and how it connects to your data
- Inserting merge fields into email content without writing code
- Content variables and how they let you define reusable values across an email
- Dynamic variations for showing different content blocks based on data conditions
- Accessing data graph attributes through the no-code personalization interface
- Limitations of no-code personalization and when you need Handlebars instead
