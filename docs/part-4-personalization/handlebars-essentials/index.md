## Overview

## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Handlebars expression syntax: double curly braces, helpers, and block helpers
- The `get` helper vs dot notation for accessing data graph attributes
- Using `with` to set context and shorten repeated paths
- Accessing unified individual, related lists, and calculated insights from the data graph
- Conditional logic with `if`, `unless`, and `equals`
- Providing fallback values for missing or null data
- String helpers for formatting names and text
- The `each` helper for looping over related records
- How AMPscript relates to Handlebars in MCA (AMPscript compiles to Handlebars under the hood)
