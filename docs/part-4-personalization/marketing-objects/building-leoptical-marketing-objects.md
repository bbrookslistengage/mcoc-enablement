## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Creating a Product Catalog Marketing Object for LEOptical eyewear products
- Creating a Loyalty Tier Thresholds Marketing Object for tier definitions and point ranges
- Defining fields, data types, and primary keys for each Marketing Object
- Preparing and formatting CSV files for import
- Importing records into Marketing Objects via the CSV upload flow
- Verifying imported records and troubleshooting common import errors
