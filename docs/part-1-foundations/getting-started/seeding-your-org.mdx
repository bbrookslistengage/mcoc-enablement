## About the course data

The seed script populates your SDO with LEOptical's fictional customer data. Once it runs, your org will contain:

- Approximately 60,000 Contacts with realistic names, loyalty tiers, and purchase histories
- 5 Products (the 4 lens families plus frames)
- 3 Campaigns you will reference throughout the course: Spring Collection 2026, VisionCare Rewards Launch, and Back to School

All of this data lives in a single Apex script. There is no CSV to import at this stage.

:::info
Almost all 60,000 contacts have `@example.com` email addresses. The `example.com` domain is reserved by the IETF (RFC 2606) and does not deliver to any real inbox. You can send to these contacts freely throughout the course without worrying about real emails going anywhere.

The 10 test contacts described below are the only exceptions. They are the contacts you will actually receive emails from.
:::

## Run the seed script

1. In your org, click the **gear icon** in the top-right corner and select **Developer Console**.

   {/* SCREENSHOT: Developer Console option in the gear menu */}

2. In the Developer Console, go to **Debug > Open Execute Anonymous Window** (or press **Ctrl+E** / **Cmd+E**).

   {/* SCREENSHOT: Developer Console with the Debug menu open */}

3. Copy the script above using the copy button, then paste it into the Execute Anonymous window.

4. Check **Open Log** at the bottom of the window, then click **Execute**.

   {/* SCREENSHOT: Execute Anonymous window with script pasted and Open Log checked */}

5. The log window will open. The script takes 2-5 minutes to complete. When it finishes, the last log line will read `Execution finished`.

   {/* SCREENSHOT: Log window showing "Execution finished" */}

:::warning
If the log shows an error (red text or an exception), do not proceed. Copy the error message and check the troubleshooting notes in the course repo's `README.md`. The most common cause is hitting DML governor limits. The script is designed to run on a fresh SDO, not an org that already has data.
:::

## Record the Campaign IDs

The seeded campaigns have Salesforce Record IDs you will reference in later modules when building segments and journeys.

10. Navigate to **Campaigns** in the App Launcher.
11. Open each seeded campaign and copy the 18-character Salesforce Record ID from the URL. It is the portion of the URL after `/lightning/r/Campaign/` and before `/view`.
12. Save the three IDs somewhere accessible: a notes file, a spreadsheet, anywhere you can find them later.

The campaigns to record: Spring Collection 2026, VisionCare Rewards Launch, Back to School.
