## Overview

## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- How templates work as reusable starting points for new emails
- Why templates do not propagate changes to emails created from them
- Content blocks vs sections: the propagation distinction and when each is appropriate
- Locked and editable regions within a template
- Locking strategies: fully locked, partially locked, and fully editable approaches
- How HTML paste emails work and when they are the right choice
- Planning template architecture for a multi-email program
