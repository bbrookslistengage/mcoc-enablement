## Overview

## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Create a shared header content block with the LEOptical logo and navigation links
- Create a shared footer content block with legal text and unsubscribe link
- Build a reusable Product Card content block for product spotlight emails
- Test propagation by editing a content block and confirming changes appear in all linked emails
- Convert a content block to a section and verify that propagation stops
- Build an email that uses your new content blocks
