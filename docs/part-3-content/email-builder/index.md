## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- The drag-and-drop email editor and its interface layout
- All builder elements: text, image, button, divider, HTML, and dynamic content
- Sections and how they structure email layout
- The Data Sources tab and connecting a data graph to an email
- Content Variables and how they inject dynamic values
- Preview and test tools for validating emails before sending
- HTML paste emails and when to use them
- Locked vs editable regions and how they control what senders can change
