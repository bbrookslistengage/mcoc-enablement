## Overview

## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Creating an activation template for LEOptical email sends
- Configuring contact point selection rules to target the correct email address
- Activating the VIP Customers segment using the new activation template
- Activating the Lapsed Buyers segment and verifying recipient counts
- Testing contact point selection with contacts that have multiple email addresses
- Confirming that the activation template prevents the "all email addresses" default behavior
- Reviewing activation results and troubleshooting common contact point selection issues
