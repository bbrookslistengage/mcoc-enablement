## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Marketing flows vs. standard flows and when to use each
- Flow trigger types: record-triggered, schedule-triggered, and automation event-triggered
- Entry criteria and how they filter which records enter a flow
- Send Email action configuration and template selection
- Action elements: Send Email, Create Campaign Member, and other send/action nodes
- Logic and control elements: Decision, Wait, Loop, and Assignment
- Data elements: Get Records, Create Records, Update Records, and Delete Records
- Flow resources: variables, constants, formulas, and text templates
- Content variables and how they pass dynamic values into email templates
- Testing and debugging flows with the Flow Debug tool
