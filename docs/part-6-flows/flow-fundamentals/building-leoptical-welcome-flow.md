## Overview

## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Creating a new Marketing Flow triggered by Loyalty Program Member record creation
- Configuring trigger entry criteria for LEOptical loyalty signups
- Adding a Send Email action and selecting the welcome email template
- Setting up content variables to personalize the welcome email
- Adding a Create Campaign Member action to track flow recipients
- Connecting flow elements and configuring the flow path
- Testing the flow end-to-end with a test Loyalty Program Member record
- Verifying email delivery and Campaign Member creation after the test run
