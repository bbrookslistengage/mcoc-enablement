## Overview

## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Building a subflow that handles common email send logic for reuse across multiple LEOptical flows
- Configuring input and output variables for the subflow interface
- Calling the subflow from an existing LEOptical flow using the Subflow element
- Setting up batch processing for a large-segment campaign send
- Configuring re-entry settings to allow contacts to receive recurring promotional campaigns
- Testing re-entry behavior by running a contact through the same flow twice
- Reviewing flow interview records to troubleshoot and verify execution history
