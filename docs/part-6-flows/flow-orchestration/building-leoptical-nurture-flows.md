## Overview

## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Expanding the LEOptical welcome flow into a 3-email nurture series
- Adding wait steps between emails to space out the nurture cadence
- Building a decision branch that checks whether the contact opened or clicked the previous email
- Configuring different email content for engaged vs. unengaged contacts
- Building a post-purchase review request flow triggered by Sales Order completion
- Using an automation event trigger on the Sales Order object
- Adding a 14-day wait step before sending the transactional review request email
- Testing both flows end-to-end and verifying correct branching and timing behavior
