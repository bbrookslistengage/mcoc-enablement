## Lesson overview

This section contains a general overview of topics that you will learn in this lesson.

- Decision branches and how to route contacts down different paths based on field values or engagement data
- Wait steps: time-based waits, date-based waits, and event-based waits
- Path experiments for A/B testing different flow branches against each other
- Einstein Decision and how it selects the best path for each individual contact
- Using content variables to pass dynamic data into emails at each step of a multi-touch flow
- Combining decision logic with wait steps to build responsive nurture sequences
- Automation event-triggered flows and how they differ from record-triggered flows
- Designing flows that react to contact behavior between send steps
